PyDepM

PyDepM (Gestor de Dependencias de Python) es una herramienta moderna de gestión de dependencias para proyectos Python que combina la simplicidad de npm con el potente ecosistema de empaquetado de Python. Ofrece dos herramientas principales: pydep para la gestión de dependencias y el andamiaje de proyectos, y pydepx para una mejor ejecución de scripts.
